# Texto sugerido para hoja de vida

**Proyecto académico: Análisis de producción textil y dashboard interactivo**  
*Python · pandas · NumPy · Plotly · Google Colab · HTML · CSS*

- Generación, depuración y análisis de una base de datos simulada de 20 registros diarios de producción textil.
- Cálculo de indicadores de cumplimiento, calidad y productividad, con reportes por semana y tipo de prenda.
- Diseño de dashboard interactivo en Google Colab y exportación de un reporte visual en HTML para consulta desde el navegador.
- Documentación de los resultados, limitaciones del modelo y recomendaciones exploratorias para seguimiento operativo.

**Frase para entrevista:** «Desarrollé un proyecto académico utilizando datos simulados para practicar la limpieza, agregación y visualización de datos de producción. Construí un dashboard con Plotly y exporté una versión HTML, de modo que los resultados pudieran explorarse sin ejecutar Python».
